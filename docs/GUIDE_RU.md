# Руководство пользователя Gemma Local Desktop — Локальный ИИ-ассистент и среда разработки под Windows

> [!NOTE]
> **TL;DR: Краткая сводка**
> - **ИИ без облака**: Полностью автономный запуск на Windows с использованием моделей Google Gemma через `llama.cpp`.
> - **Двухпанельный интерфейс**: Простое переключение между обычным чатом и активной разработкой кода.
> - **Интерактивный просмотр**: Мгновенное отображение созданных HTML/CSS/JS-приложений во встроенном WebView.
> - **Локальная песочница**: Итеративное редактирование сохраняет файлы проектов напрямую на ваш диск.

---

Gemma Local Desktop — это настольный ассистент, который переносит всю мощность приватного искусственного интеллекта прямо на ваш компьютер с Windows. Благодаря локальному запуску оптимизированных весов моделей Google Gemma, это приложение исключает зависимость от облачных сервисов, платную подписку и проблемы конфиденциальности, позволяя вам создавать веб-приложения и анализировать сложную логику на 100% офлайн.

---

## Возможности приложения

### Режим чата (Chat Mode)
Режим чата предоставляет интерфейс, оптимизированный для стандартного текстового диалога. Он лучше всего подходит для объяснения концепций, обзора существующих фрагментов кода, проработки логики и поиска ошибок в программах. Вывод оформляется в виде понятного и легко читаемого Markdown.

### Режим сборки (Build Mode)
Режим сборки разделяет экран на две панели для генерации интерактивных веб-приложений (HTML, CSS, JS). По мере написания кода модель сохраняет файлы в локальную песочницу, и они мгновенно отображаются во встроенном окне предпросмотра шириной 720px.

### Окно живого просмотра (Live Preview Canvas)
Панель просмотра использует Microsoft WebView2 для рендеринга созданного веб-контента в реальном времени. Кнопка быстрого запуска позволяет открыть созданное приложение в браузере по умолчанию для полноэкранного тестирования и инспекции элементов.

### Песочница проектов (Workspace Sandbox)
Каждый новый чат сохраняет файлы в отдельную папку на диске. Корректировки выполняются итеративно — если вы просите модель изменить цвет кнопки или добавить функционал, она обновляет конкретные файлы в каталоге проекта, после чего окно просмотра автоматически перезагружает страницу.

## Локализация и языки интерфейса

Интерфейс Gemma Local Desktop автоматически определяет язык операционной системы Windows при запуске.

### Поддерживаемые языки
- **Английский** (используется по умолчанию)
- **Русский**
- **Немецкий**

### Параметры переопределения языка
Если вы хотите запустить приложение на определенном языке независимо от системных настроек, вы можете запустить исполняемый файл через командную строку или PowerShell с параметром `--lang`:
```powershell
# Запуск приложения на русском языке
GemmaChatWindows.exe --lang ru

# Запуск приложения на немецком языке
GemmaChatWindows.exe --lang de

# Запуск приложения на английском языке
GemmaChatWindows.exe --lang en
```

## Пошаговая инструкция для быстрого старта

Выполните следующие шаги, чтобы подготовить локального ассистента к работе за несколько минут:

1. **Шаг 1: Скачивание и клонирование** — Склонируйте репозиторий с помощью Git или скачайте ZIP-архив с исходным кодом и распакуйте его в удобную папку на компьютере.
2. **Шаг 2: Проверка предварительных требований** — Убедитесь, что на вашем компьютере установлен SDK .NET 10.0 для компиляции и сборки проекта.
3. **Шаг 3: Запуск приложения** — Откройте консоль в папке проекта и запустите сборку командой `dotnet run` внутри каталога `GemmaChatCsharp`.
4. **Шаг 4: Автоматическая настройка ресурсов** — Подождите, пока приложение проверит видеокарту, скачает совместимые бинарные файлы сервера `llama.cpp` и загрузит рекомендуемую модель Gemma (~1.6 ГБ).
5. **Шаг 5: Выбор готового шаблона** — Нажмите на карточку любого предустановленного шаблона на стартовом экране (например, **Mega Tetris** или **Weather Dashboard**), чтобы загрузить готовый промпт, и нажмите Enter для запуска генерации кода.

## Советы и горячие клавиши

Используйте встроенные горячие клавиши для быстрой работы в приложении:

| Горячие клавиши | Действие / Описание |
| --- | --- |
| `Ctrl + N` | Начать новый чат и очистить рабочую область. |
| `Ctrl + B` | Переключить режим разделенного экрана (между режимом Чат и Сборка). |
| `Ctrl + \` | Показать/скрыть правую панель холста сборки (код и интерактивное превью). |

## Часто задаваемые вопросы и решение проблем

### Windows Defender SmartScreen блокирует приложение при запуске
Поскольку скомпилированные исполняемые файлы бесплатных проектов с открытым кодом не подписываются дорогостоящими сертификатами, Windows выдает предупреждение. Нажмите **Подробнее** и затем **Выполнить в любом случае**, чтобы продолжить запуск.

### Видеокарта не используется, генерация идет слишком медленно
Приложение поддерживает аппаратное ускорение на видеокартах NVIDIA с CUDA. Установите последние драйверы NVIDIA. Если подходящей видеокарты нет, вычисления перейдут на процессор (CPU), что замедлит генерацию. Также закройте другие ресурсоемкие программы, чтобы освободить не менее 4 ГБ ОЗУ.

### Сброс настроек и повторная загрузка файлов
Если файлы были повреждены или загрузка прервалась, перейдите в папку AppData вашего пользователя (`%LocalAppData%\GemmaLocalDesktop`) и удалите папки `runtimes` или `models`, чтобы запустить повторную загрузку при следующем старте приложения.
